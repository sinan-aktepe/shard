# Shard 2.0 — F3 (StateStorage.delete + clearPersistence) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: subagent-driven-development / executing-plans. Checkbox steps.

**Goal:** Add a real per-key `StateStorage.delete(key)` (BREAKING for implementers) and a `clearPersistence()` on `StatePersistenceMixin` that uses it — the logout/wipe story, replacing the 1.x empty-string workaround.

**Architecture:** `delete` joins the `StateStorage` interface; `FakeStateStorage` implements it (with the same counter/injection pattern as `save`/`load`). `clearPersistence()` cancels the pending debounced save, then chains `storage.delete(key)` onto the existing `_saveQueue` so it can't race a queued write; delete failures route to `onSaveError`. It does not touch in-memory state.

**Reference spec:** `docs/superpowers/specs/2026-06-13-shard-2.0-design.md` §3 F3. Branch `feature/2.0-dev`. The only in-repo `StateStorage` implementer is `FakeStateStorage` (plus the doc-comment example in `storage.dart`).

- [ ] **Step 3: Implement `clearPersistence`**

In `lib/src/persistence/state_persistence.dart`, add this method to `StatePersistenceMixin` immediately after `disablePersistence()`:

```dart
  /// Clears this shard's persisted slice from storage (e.g. on logout).
  ///
  /// Cancels any pending debounced auto-save, then deletes the stored value
  /// via [StateStorage.delete], chained onto the save queue so it cannot race
  /// a previously queued write. A subsequent [loadState] calls [onLoadComplete]
  /// with `null` (no data). Delete failures are routed to [onSaveError].
  ///
  /// This does NOT change the in-memory state — pair it with
  /// `emit(initialState)` if you also want to reset the live state.
  Future<void> clearPersistence() async {
    final config = _persistenceConfig;
    if (config == null) return;
    cancelDebounce(_autoSaveDebounceKey);
    _saveQueue = _saveQueue.then((_) async {
      try {
        await config.storage.delete(config.key);
      } catch (error, stackTrace) {
        config.onSaveError?.call(error, stackTrace);
      }
    });
    return _saveQueue;
  }
```
